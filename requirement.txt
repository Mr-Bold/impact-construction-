Build a modern, professional, responsive full-stack web application for a business that wants to showcase its completed work and allow customers to interact with projects and request similar services.

## PROJECT OBJECTIVE

Create an interactive **Work Showcase & Customer Service Request Platform**.

The business administrator should be able to upload photos and videos of completed projects. Customers should be able to browse the projects, watch videos, view images, like, rate, comment, share projects, and request the same or similar service.

The platform should feel like a professional modern business website combined with a lightweight customer-management system.

---

# TECHNOLOGY STACK

Use:

- Frontend: React.js
- Backend: Node.js + Express.js
- Database: Supabase PostgreSQL
- Supabase Storage for images, videos, and customer attachments
- REST API architecture
- Modern CSS/Tailwind CSS
- Responsive design
- Authentication with secure role-based access
- PWA support so the website can be installed on mobile devices
- Environment variables for all secrets and configuration

Structure the application cleanly with separate frontend and backend directories.

# FINAL USER EXPERIENCE

The complete flow should work like this:

1. Visitor opens the website.
2. Visitor sees the business and its services.
3. Visitor browses completed projects.
4. Visitor opens a project.
5. Visitor watches the video/views images.
6. Visitor can like, rate, comment, or share.
7. Visitor clicks "Request This Service".
8. Visitor submits their information.
9. The request enters the admin dashboard.
10. Admin receives a notification.
11. Admin reviews the request.
12. Admin communicates with the customer.
13. Admin optionally sends a quotation.
14. Customer accepts or declines.
15. Admin updates the job status.
16. Customer tracks the progress from their dashboard.
17. Once completed, the customer can leave a review.
