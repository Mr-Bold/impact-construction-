SETUP STEPS
════════════════════════════════════════════════════════════════════════════

1. CREATE SUPABASE PROJECT
   → Visit supabase.com
   → Create new project
   → Get URL and API keys

2. RUN DATABASE MIGRATION
   → Go to Supabase SQL Editor
   → Copy backend/sql/01_create_tables.sql
   → Paste and execute

3. CREATE STORAGE BUCKETS
   → project-media
   → request-attachments
   → profile-photos

4. CONFIGURE BACKEND
   → Edit backend/.env with Supabase credentials
   → npm install in backend/
   → npm start

5. CONFIGURE FRONTEND
   → Edit frontend/.env with API URL
   → npm install in frontend/
   → npm run dev

6. ACCESS APPLICATION
   → Frontend: http://localhost:5173
   → Backend: http://localhost:3000
   → API Health: http://localhost:3000/api/health

TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

Port Already in Use:
  → Edit .env to change PORT or CORS_ORIGIN
  → Or stop other services using those ports

Module Not Found:
  → Run: npm install
  → Clear cache: npm cache clean --force

Database Connection Error:
  → Verify Supabase URL and keys in .env
  → Check that SQL migration was run
  → Ensure Supabase project is active

CORS Errors:
  → Check FRONTEND_URL in backend/.env
  → Ensure frontend port matches
  → Restart backend server
